# HR Employee Attrition Analysis

## Project Overview
This project aims to analyze and understand employee attrition using HR data. It covers data loading, cleaning, exploratory data analysis (EDA), key performance indicator (KPI) development, and categorical analysis to identify factors influencing employee turnover. The ultimate goal is to provide data-driven insights and recommendations to improve employee retention.

## Key Analysis Areas
*   **Data Preparation:** Loading, inspecting, cleaning (missing values, duplicates), and feature engineering.
*   **Exploratory Data Analysis (EDA):** Visualizing distributions of key variables and relationships between them, including attrition, age, monthly income, and job satisfaction.
*   **KPI Development:** Calculation of essential HR metrics such as attrition rate, average monthly income, and average job satisfaction.
*   **Category Analysis:** Deeper dives into attrition rates and income levels across different departments and job satisfaction groups.
*   **Employee Analysis:** Understanding income distribution by attrition status and job satisfaction by department.
*   **Top Performers:** Illustrative identification of top performers based on job satisfaction.
*   **Visualizations:** Correlation heatmaps and other plots to highlight significant relationships.
